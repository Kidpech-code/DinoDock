# 🦖 DinoDock

ไดโนเสาร์พิกเซลอาร์ต (T-rex สไตล์ 8-bit สีส้ม) ที่เดินเพ่นพ่านบนขอบ Dock ของ macOS
มีพฤติกรรมหลากหลายแบบสุ่มเหมือนมีชีวิต
*An orange 8-bit T-rex that roams your macOS Dock with a mind of its own.*

DinoDock เป็นแอปเล็ก ๆ ที่อยู่บน menu bar ไม่มีหน้าต่างหลัก **โปร่งใสและคลิกทะลุได้**
จึงไม่บัง Dock และไม่รบกวนการใช้งานปกติ

---

## คุณสมบัติ (Features)

- **พฤติกรรมหลากหลายแบบสุ่มธรรมชาติ** — เดิน วิ่ง หยุดพัก หันมอง กระโดด งีบหลับ
  ไล่ล่าเหยื่อ กินเนื้อ และพ่นคำคมเป็นครั้งคราว สลับกันแบบสุ่มถ่วงน้ำหนัก พร้อมกะพริบตา
  *(see the behaviour table below)*
- **ท่าเดินมีชีวิต** — วงจรการก้าว 4 จังหวะ ขยับเท้าสลับสองข้าง + ตัวเด้งเบา ๆ ไม่ใช่ลื่นไถล
- **ปรับขนาดได้** — เลือกขนาดตัวจากเมนู `Size` (50%–150%, เริ่มต้น 80%) คมชัดทุกขนาด จดจำค่าไว้
- **ตอบสนองการพิมพ์ (เปิด/ปิดได้)** — โชว์ตัวอักษรที่พิมพ์ในกรอบคำพูดเหนือหัว *(opt-in)*
- **เดินตามกรอบ Dock จริง** — จำกัดให้เดินในแผง Dock ที่มองเห็น ไม่หลุดนอกขอบจอ
  เลือกได้ระหว่างเดินเฉพาะบน Dock หรือเต็มความกว้างจอ
- **โปร่งใสและคลิกทะลุ** ไม่บัง Dock หรือเดสก์ท็อป

---

## พฤติกรรม (Behaviours)

| พฤติกรรม | รายละเอียด |
|---|---|
| **เดิน / วิ่ง** (walk / run) | เดินไปมาขยับเท้าสลับข้าง — วิ่งเร็วกว่า |
| **หยุดพัก** (idle) | ยืนนิ่ง กะพริบตาเป็นระยะ |
| **มองรอบ** (look) | หันหน้าสลับไปมาเหมือนสำรวจ |
| **กระโดด** (hop) | กระโดดเป็นจังหวะ 2–5 ครั้ง |
| **งีบหลับ** (sleep) | หลับตา มี `zzz` ลอยเหนือหัว |
| **ไล่ล่า** (chase) | เหยื่อตัวเล็กสีม่วงโผล่มาแล้ววิ่งหนี ไดโนวิ่งไล่จนจนมุม |
| **กินเนื้อ** (eat) | กัดกินชิ้นเนื้อ (หลังจับเหยื่อได้ หรือสุ่มกินเอง) |
| **พ่นคำคม** (speak) | โชว์คำคมด้านดีไซน์/UX/ให้กำลังใจ ในกรอบคำพูด — *นาน ๆ ครั้ง* |
| **ตอบสนองการพิมพ์** | โชว์ตัวอักษรที่กำลังพิมพ์เหนือหัว — เปิด/ปิดได้ |

การสุ่มถ่วงน้ำหนักตามสถานะปัจจุบัน (เช่น พัก → มักหลับ, หลับ → ตื่นมาเดิน) และระยะเวลาแต่ละช่วง
สุ่มเป็นวินาที จึงไม่ซ้ำจังหวะเดิม

## การติดตั้ง (Installation)

ต้องมี Xcode command-line tools เปิด Terminal แล้วรัน:

```bash
cd DinoDock
./build.sh
open DinoDock.app
```

ไดโนจะปรากฏบน Dock ทันที และมีไอคอน 🦖 อยู่บน menu bar

> **อยากให้สิทธิ์ติดถาวรแม้ build ใหม่ (ทางเลือก):** รัน `./make-signing-cert.sh` **ครั้งเดียว**
> ก่อน `./build.sh` — สคริปต์จะสร้าง self-signed certificate ในเครื่องและให้ build เซ็นด้วยมัน
> แทน ad-hoc ทำให้ macOS จำสิทธิ์ที่เปิดไว้ได้แม้ build ใหม่ (ดูหัวข้อ *สิทธิ์* ด้านล่าง)

> **หมายเหตุเรื่องความปลอดภัย:** แอปนี้เซ็นในเครื่อง (ad-hoc หรือ self-signed — ไม่ได้รับรองจาก Apple)
> หากระบบเตือนว่าเปิดไม่ได้ ให้คลิกขวาที่ `DinoDock.app` → **Open** → **Open** อีกครั้ง
> หรือรัน `xattr -dr com.apple.quarantine DinoDock.app`

## การใช้งาน (Usage)

คลิกไอคอน 🦖 บน menu bar เพื่อเปิดเมนู:

| เมนู | ความหมาย |
|---|---|
| **Walk area ▸ On the Dock** | ให้ไดโนเดินเฉพาะบนแผง Dock (ค่าเริ่มต้น) |
| **Walk area ▸ Full screen width** | ให้ไดโนเดินเต็มความกว้างจอ |
| **Size ▸ 50%–150%** | ปรับขนาดตัวไดโน (ค่าเริ่มต้น 80%) |
| **React to typing** | เปิด/ปิดการแสดงตัวอักษรที่พิมพ์ (ต้องเปิดสิทธิ์ Input Monitoring) |
| **Track Dock exactly (Accessibility)…** | เปิดสิทธิ์เพื่อใช้กรอบ Dock จริง *(ทางเลือก)* |
| **Quit DinoDock** | ปิดแอป |

ตัวเลือกพื้นที่เดิน / ขนาด / การตอบสนองการพิมพ์ จะถูกจดจำไว้ใช้ครั้งถัดไปโดยอัตโนมัติ

## สิทธิ์ที่ขอ (Permissions)

DinoDock ขอสิทธิ์ **2 อย่าง ซึ่งเป็นทางเลือกทั้งคู่** — แอปทำงานได้โดยไม่ต้องเปิดเลย
จะขอก็ต่อเมื่อคุณเปิดใช้ฟีเจอร์ที่เกี่ยวข้อง:

| สิทธิ์ | ใช้ทำอะไร | จำเป็นไหม |
|---|---|---|
| **Accessibility** | อ่านกรอบ Dock จริงเพื่อเดินชิดขอบเป๊ะระดับพิกเซล | ไม่จำเป็น — ปกติประมาณเอาได้แม่นพอ |
| **Input Monitoring** | รับคีย์ที่พิมพ์ เพื่อโชว์เหนือหัว (ฟีเจอร์ React to typing) | จำเป็น *เฉพาะ* เมื่อจะใช้ฟีเจอร์นี้ |

### วิธีเปิดสิทธิ์

1. คลิกเมนูที่เกี่ยวข้อง (**Track Dock exactly…** หรือ **React to typing**)
   จะมีกล่องเด้งพร้อมปุ่ม **“Open System Settings”** ที่ลิงก์ไปหน้าที่ถูกต้องให้เลย
2. ในหน้านั้น เปิดสวิตช์ให้ **DinoDock**
3. **ถ้าไม่เห็น DinoDock ในรายการ** ให้กดปุ่ม **`+`** → กด `⌘⇧G` → วางพาธของแอป
   (เช่น `~/DinoDock/DinoDock.app`) → **Open** แล้วเปิดสวิตช์

> ⚠️ **ทำไมบางครั้งสิทธิ์หาย / ไม่ขึ้นในรายการ:** ถ้าเซ็นแบบ ad-hoc พอ `./build.sh`
> ใหม่ ลายเซ็นจะเปลี่ยน → macOS มองเป็นคนละแอป จึงต้องเปิดสิทธิ์ใหม่
> **วิธีแก้ให้ติดถาวร:** รัน `./make-signing-cert.sh` ครั้งเดียว แล้ว `./build.sh` จะเซ็นด้วย
> self-signed certificate ในเครื่อง (ลายเซ็นคงที่) → เปิดสิทธิ์ครั้งเดียวอยู่ถาวรแม้ build ใหม่
> *(ถ้าไม่รันสคริปต์นี้ แอปจะเซ็น ad-hoc ตามปกติ — ใช้ได้เหมือนกัน แค่ต้องเปิดสิทธิ์ใหม่เมื่อ build)*

> 🔒 **ความเป็นส่วนตัวของฟีเจอร์พิมพ์:** ตัวอักษรแสดงชั่วคราวเหนือไดโนแล้วจางหาย
> *ไม่มีการบันทึกหรือส่งออกที่ใดทั้งสิ้น* และจะ **ไม่แสดงเมื่ออยู่ในช่องรหัสผ่าน** (secure input) อัตโนมัติ

## การปรับแต่ง (Customization)

ซอร์สโค้ดทั้งหมดอยู่ใน `Sources/DinoDock/`:

| อยากเปลี่ยน | แก้ที่ |
|---|---|
| รูปร่าง / สีไดโน / เหยื่อ / เนื้อ | `DinoPixelArt.swift` (กริดตัวอักษร) และ `palette` ใน `PetView.swift` |
| พฤติกรรม / น้ำหนักการสุ่ม / ระยะเวลา | `startBehavior`, `nextBehavior` — `PetController.swift` |
| จังหวะ / ท่าก้าวเดิน (walk cycle) | `walkPhase` ใน `updateAppearance` + เฟรม `walkB`/`walkC` — `DinoPixelArt.swift` |
| ความเร็วเดิน / วิ่ง / ความสูงกระโดด | `move()`, `hopHeight` — `PetController.swift` |
| ตัวเลือกขนาด (เปอร์เซ็นต์) | `sizeOptions` — `PetController.swift` |
| เฟรมเรต / จังหวะ animation | ค่าคงที่ `fps`, `hopLen` — `PetController.swift` |
| รายการคำคม | `Quotes.swift` |
| การจับคีย์บอร์ด / กรอบคำพูด | `KeyboardWatcher.swift`, `drawBubble` ใน `PetView.swift` |
| ตรรกะการหาตำแหน่ง Dock | `DockGeometry.swift` |

> **เกร็ดการตรวจงานอาร์ต:** ไดโนตัวจริงบน Dock เล็กและขยับตลอด ดูยาก — ให้เรนเดอร์กริด
> ใน `DinoPixelArt.swift` ออกเป็น PNG ขยายใหญ่นอกแอป (คอมไพล์ harness เล็ก ๆ คู่กับไฟล์อาร์ต)
> แล้วเปิดดูภาพแทน จะเช็กรูปร่าง/สี/ท่าเดินได้ชัดกว่า

## โครงสร้างโค้ด (Architecture)

| ไฟล์ | หน้าที่ |
|---|---|
| `main.swift` | จุดเริ่มต้นของแอป (เป็น agent บน menu bar) |
| `AppDelegate.swift` | วงจรชีวิตของแอป |
| `PetController.swift` | สร้างหน้าต่าง จัดการเมนู สเตตแมชชีนพฤติกรรม ขนาด และลูป animation |
| `PetView.swift` | วาดสไปรต์ไดโน เหยื่อ เนื้อ และกรอบคำพูด (คมชัดทุกสเกล) |
| `DinoPixelArt.swift` | พิกเซลอาร์ตของไดโน (stand / walkB / walkC / blink) เหยื่อ และชิ้นเนื้อ |
| `KeyboardWatcher.swift` | จับการพิมพ์ทั้งระบบ (เมื่อเปิดใช้) เพื่อนำตัวอักษรไปแสดง |
| `Quotes.swift` | รายการคำคมที่ไดโนสุ่มพ่นออกมานาน ๆ ครั้ง |
| `DockGeometry.swift` | คำนวณกรอบ Dock (ผ่าน Accessibility หรือการประมาณจาก preferences) |
| `WalkMode.swift` | โหมดการเดินและการจดจำค่า |

สร้างด้วย **Swift + AppKit** ล้วน ๆ (ลิงก์ `Cocoa` + `Carbon`) ไม่มี dependency ภายนอก

## สร้างผ่าน Xcode (ทางเลือก)

1. **File ▸ New ▸ Project… ▸ macOS ▸ App** — Interface = **AppKit App Delegate**, Language = **Swift**
2. ลบไฟล์ที่ Xcode สร้างให้ (`ViewController.swift`, `Main.storyboard`, `AppDelegate.swift` เริ่มต้น)
3. ลากไฟล์ทั้งหมดใน `Sources/DinoDock/` เข้าโปรเจกต์
4. ใน **Target ▸ Info** ตั้งค่า `Application is agent (UIElement)` = `YES`
5. หากมี `@main` ซ้ำให้ลบออก — entry point อยู่ใน `main.swift`
6. กด **Run** ▶︎

---

## ข้อจำกัด (Limitations)

- แสดงบนจอหลัก (main display) เพียงจอเดียว
- รองรับ Dock ด้านล่างเต็มรูปแบบ — หาก Dock อยู่ด้านซ้าย/ขวา หรือซ่อนอัตโนมัติ
  ไดโนจะเดินตามขอบล่างของพื้นที่ใช้งานแทน
- ต้องใช้ macOS 11 (Big Sur) ขึ้นไป

---

## ถอนการติดตั้ง (Uninstall)

ปิดแอปจากเมนู 🦖 → **Quit DinoDock** แล้วลบ `DinoDock.app`
หากเคยเปิดสิทธิ์ไว้ ปิดได้ที่ **System Settings ▸ Privacy & Security** ใต้หัวข้อ
**Accessibility** และ **Input Monitoring**
